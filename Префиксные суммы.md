# Префиксные суммы

[[Linear algorithm|← Назад к Линейным алгоритмам]]

## Префиксные суммы
* **Суть понятия:**
	* Время работы алгоритма линейно зависит от объема входных данных $n$.
	* Масштабируемость: если объем входных данных увеличивается в $X$ раз, то количество элементарных операций и время выполнения программы возрастают тоже примерно в $X$ раз.
	* Специальная структура данных, позволяющая мгновенно отвечать на $m$ запросов суммы элементов на отрезке за константное время $O(1)$.
* **Математическое объяснение:**
	* Функция реального количества операций алгоритма $k(n)$ ограничена сверху функцией $C \cdot n$, начиная с некоторого значения $n_0$.
	* В $i$-м элементе массива $p$ размера $n + 1$ хранится сумма первых $i$ элементов массива $a$: $p_i = p_{i-1} + a_{i-1}$, при этом стартовое значение $p_0 = 0$.
	* Сумма элементов на произвольном отрезке $[l; r]$ вычисляется за один шаг как разность двух префиксов: $p_{r+1} - p_l$.
* **Поведение при больших n:**
	* При росте $n$ до миллиона элементов алгоритм $O(n)$ выполнит порядка миллиона операций на этапе предподсчета.
	* В отличие от неэффективных алгоритмов ($O(m \cdot n)$), линейные алгоритмы отлично подходят для обработки больших массивов данных в реальном времени.
* **Реализация на C++:** 
```cpp
#include <ios>
#include <iostream>

using namespace std;

int main() {
    cin.tie(0);
    ios_base::sync_with_stdio(0);

    int n, m;
    cin >> n >> m;

    int a[n + 1];
    int pref[n + 2];
    pref[0] = 0;

    for (int i = 0; i < n; i++) {
        cin >> a[i];
        pref[i + 1] = pref[i] + a[i];
    }

    for (int i = 0; i < m; i++) {
        int L, R;
        cin >> L >> R;

        cout << pref[R + 1] - pref[L] << " ";
    }
}
```

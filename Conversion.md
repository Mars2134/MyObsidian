# Конверсия (Conversion)
- **Суть:** Способ образования нового слова, при котором оно переходит из одной части речи в другую без изменения написания и произношения. Значение слова меняется в зависимости от контекста и его синтаксической роли в предложении. В ОГЭ в качестве ответа не требуется, но критически важно для понимания текстов.
- **Переход «Существительное → Глагол» (Самый частый тип):**
	- Water (вода) → to water (поливать)
	- Phone (телефон) → to phone (звонить по телефону)
	- Hand (рука) → to hand (вручать / передавать)
	- Book (книга) → to book (бронировать)
	- Google (Гугл) → to google (искать в Гугле)
- **Переход «Глагол → Существительное»:**
	- To walk (гулять) → a walk (прогулка)
	- To look (смотреть) → a look (взгляд / вид)
	- To run (бежать) → a run (пробежка)
	- To cry (плакать) → a cry (плач / крик)
- **Переход «Прилагательное → Глагол»:**
	- Clean (чистый) → to clean (чистить / убирать)
	- Empty (пустой) → to empty (опустошать)
	- Dry (сухой) → to dry (сушить)

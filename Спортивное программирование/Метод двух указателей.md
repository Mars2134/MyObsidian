# Метод двух указателей

[[Linear algorithm|← Назад к Линейным алгоритмам]]

## Метод двух указателей
* **Суть понятия:**
	* Время работы алгоритма линейно зависит от объема входных данных $n$.
	* Масштабируемость: если объем входных данных увеличивается в $X$ раз, то количество элементарных операций и время выполнения программы возрастают тоже примерно в $X$ раз.
	* Способ поиска непрерывного отрезка с заданной суммой $k$ в массивах, состоящих строго из неотрицательных элементов.
* **Математическое объяснение:**
	* Функция реального количества операций алгоритма $k(n)$ ограничена сверху функцией $C \cdot n$, начиная с некоторого значения $n_0$.
	* Условие: за счет неотрицательности элементов функция суммы монотонна — сдвиг правого указателя увеличивает сумму в окне, сдвиг левого — уменьшает.
	* Во время исполнения алгоритма каждый из двух указателей примет не более $n$ различных значений, поэтому общее число действий гарантированно не превысит $2n$.
* **Поведение при больших n:**
	* При росте $n$ до миллиона элементов алгоритм $O(n)$ выполнит порядка миллиона операций.
	* В отличие от неэффективных алгоритмов ($O(n^2)$), линейные алгоритмы отлично подходят для обработки больших массивов данных в реальном времени.
* **Реализация на C++:**
	```cpp
	int i = 0, j = 0, s = a;
	bool go = true;
	while (go) {
		if (s == k) {
			go = false;
		} else if (s < k) {
			if (j == n - 1) {
				go = false;
			} else {
				s += a[++j];
			}
		} else {
			s -= a[i++];
		}
	}
	if (s == k) cout << i << " " << j << endl;
	else cout << "-1 -1" << endl;
	```

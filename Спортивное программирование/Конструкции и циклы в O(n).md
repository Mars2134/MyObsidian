# Конструкции и циклы в O(n)
- **Главный признак линейности в коде:**
	- Наличие **одного изолированного цикла** (`for` или `while`), который итерируется ровно $n$ раз (или пропорционально $n$).
- **Внутреннее устройство цикла:**
	- Чтобы алгоритм оставался линейным, все операции *внутри* этого цикла должны иметь константную сложность $O(1)$.
	- Разрешенные операции внутри цикла: базовые математические действия, операции присваивания, ветвления `if/else`, сравнения элементов.
- **Ошибки, ломающие линейность:**
	- Если внутри цикла вызывается функция, которая сама по себе выполняет проход по массиву (например, метод `in`, `.index()`, `.count()` в Python), то общая сложность алгоритма превращается в квадратичную $O(n^2)$.

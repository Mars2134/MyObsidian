# Конструкции и циклы в O(n)

Линейная сложность $O(n)$ возникает тогда, когда общее количество операций в программе растет строго пропорционально размеру входных данных (переменной $n$). В коде на C++ это выражается через конкретные базовые конструкции.

## 1. Одиночный цикл (Базовый случай)
Самый частый пример — один цикл, который проходит от $0$ до $n$ с шагом в единицу. Количество итераций в точности равно $n$.
```cpp
// Сложность: O(n)
for (int i = 0; i < n; ++i) {
    // Операции внутри выполняются за O(1)
    int result = a[i] * 2; 
}
```

## 2. Несколько последовательных циклов
Если циклы идут друг за другом (не вложены), их сложности складываются. Константы при асимптотическом анализе отбрасываются, поэтому суммарная сложность всё равно остаётся линейной.
```cpp
// Первый цикл: n итераций
for (int i = 0; i < n; ++i) {
    a[i] = i;
}

// Второй цикл: n итераций
for (int i = 0; i < n; ++i) {
    cout << a[i];
}
// Суммарно: n + n = 2n -> это класс сложности O(n)
```

## 3. Циклы с измененным шагом (Важный нюанс)
Если цикл увеличивает счетчик на фиксированную константу (например, `i += 2` или `i += 5`), количество операций уменьшается в несколько раз, но глобальный класс сложности не меняется.
```cpp
// Сложность: O(n / 2) -> константа 1/2 отбрасывается -> O(n)
for (int i = 0; i < n; i += 2) {
    // Код выполняется только для четных индексов
}
```

## 4. Вложенный цикл, который НЕ даёт O(n²)
**Критически важно для олимпиад:** наличие вложенного цикла не всегда означает квадратичную сложность. Если внутренний цикл в сумме за все шаги внешнего цикла делает не более $n$ операций, то весь алгоритм работает за линейное время. Это называется *амортизационным анализом* (часто встречается в методе двух указателей).
```cpp
int left = 0;
// Внешний цикл увеличивает 'right' от 0 до n
for (int right = 0; right < n; ++right) {
    // Внутренний цикл сдвигает 'left', но суммарно за ВСЁ время 
    // работы программы 'left' сдвинется не более чем n раз
    while (left < right && current_sum > target) {
        current_sum -= a[left];
        left++;
    }
}
// Оба указателя прошли массив по одному разу. Сложность: O(n)
```

## Чего НЕ должно быть в линейных циклах:
1. **Вложенности вида $n \cdot n$:** Если внутри цикла от $0$ до $n$ запускается другой независимый цикл от $0$ до $n$, сложность становится квадратичной $O(n^2)$.
2. **Деления или умножения счетчика:** Если шаг цикла выглядит как `i *= 2` или `i /= 2`, то сложность падает до логарифмической $O(\log n)$ (база бинарного поиска).

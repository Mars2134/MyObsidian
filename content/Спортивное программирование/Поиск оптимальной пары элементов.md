# Поиск оптимальной пары элементов

## Поиск оптимальной пары элементов
* **Суть понятия:**
	* Время работы алгоритма линейно зависит от объема входных данных $n$.
	* Масштабируемость: если объем входных данных увеличивается в $X$ раз, то количество элементарных операций и время выполнения программы возрастают тоже примерно в $X$ раз.
	* Позволяет найти пару элементов $(a_i, a_j)$ при условии $i < j$, максимизирующую разность, без использования вложенных циклов за один проход массива.
* **Математическое объяснение:**
	* Функция реального количества операций алгоритма $k(n)$ ограничена сверху функцией $C \cdot n$, начиная с некоторого значения $n_0$.
	* Условие: для фиксированного правого элемента $a_j$ разность $(a_j - a_i)$ максимальна, когда левый элемент $a_i$ минимален на пройденном отрезке $[0; j - 1]$.
	* Индекс этого минимума ($imin$) поддерживается в актуальном состоянии и пересчитывается при увеличении $j$ на 1 за константное время $O(1)$.
* **Поведение при больших n:**
	* При росте $n$ до миллиона элементов алгоритм $O(n)$ выполнит порядка миллиона операций.
	* В отличие от неэффективных алгоритмов ($O(n^2)$), линейные алгоритмы отлично подходят для обработки больших массивов данных в реальном времени.
* **Реализация на C++:**
	```cpp
	int imin = 0;
	int ibest = 0;
	int jbest = 1;
	for (int j = 2; j < n; ++j) {
		if (a[j - 1] < a[imin]) {
			imin = j - 1;
		}
		if (a[j] - a[imin] > a[jbest] - a[ibest]) {
			jbest = j;
			ibest = imin;
		}
	}
	cout << ibest << " " << jbest << endl;
	```

# Степени сравнения прилагательных (Degrees of comparison)
- **Суть:** Изменение формы прилагательного для сравнения предметов между собой. Существует две степени: сравнительная (Comparative) — «более...» и превосходная (Superlative) — «самый...». 

- **1. Короткие прилагательные (1–2 слога):**
	- Образуются с помощью добавления суффиксов к самому слову.
	- **Comparative (Сравнительная):** суффикс `-er`.
		- Small (маленький) ➔ smaller (меньше)
		- Tall (высокий) ➔ taller (выше)
	- **Superlative (Превосходная):** артикль `the` + суффикс `-est`.
		- Small (маленький) ➔ the smallest (самый маленький)
		- Tall (высокий) ➔ the tallest (самый высокий)

- **⚠️ Важная ловушка ОГЭ: Изменения на письме для коротких слов:**
	- Если слово заканчивается на гласную + согласную, конечная согласная удваивается:
		- Big ➔ bigger ➔ the biggest (большой ➔ больше ➔ самый большой)
		- Hot ➔ hotter ➔ the hottest (горячий)
	- Если слово заканчивается на согласную + `-y`, она меняется на `-i`:
		- Happy ➔ happier ➔ the happiest (счастливый)
		- Easy ➔ easier ➔ the easiest (легкий)
	- Если слово заканчивается на `-e`, добавляется только `-r` / `-st`:
		- Large ➔ larger ➔ the largest (крупный)

- **2. Длинные прилагательные (3 и более слогов):**
	- Само слово не меняется, перед ним ставятся вспомогательные слова.
	- **Comparative (Сравнительная):** слово `more` (больше).
		- Beautiful ➔ more beautiful (более красивый)
		- Interesting ➔ more interesting (более интересный)
	- **Superlative (Превосходная):** слова `the most` (самый).
		- Beautiful ➔ the most beautiful (самый красивый)
		- Interesting ➔ the most interesting (самый интересный)

- **3. Исключения (Обязательно выучить для ОГЭ):**
	- Good (хороший) ➔ better (лучше) ➔ the best (лучший / самый хороший)
	- Bad (плохой) ➔ worse (хуже) ➔ the worst (худший / самый плохой)
	- Many / Much (много) ➔ more (больше) ➔ the most (больше всего)
	- Little (маленький / мало) ➔ less (меньше) ➔ the least (меньше всего)
	- Far (далекий) ➔ farther / further (дальше) ➔ the farthest / furthest (самый далекий)

- **💡 Маркеры-подсказки в заданиях ОГЭ:**
	- Если в предложении после пропуска стоит слово `than` (чем), всегда нужна **сравнительная степень** (`-er` / `more`).
		- Пример: This book is more interesting than that one.
	- Если перед пропуском стоит артикль `the`, почти всегда нужна **превосходная степень** (`-est` / `most`).
		- Пример: It was the happiest day of my life.

- **Пример для ОГЭ:**
	- Context: This track is ___ (GOOD) than the previous one.
	- Ответ: better
	- Context: It was the ___ (BIG) city I had ever visited.
	- Ответ: biggest *(не забывайте удваивать g)*

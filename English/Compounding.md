# Словосложение (Compounding)
- **Суть:** Образование нового слова путем соединения двух или более корней (самостоятельных слов) в одно целое. В ОГЭ в качестве целевого ответа практически не встречается, но часто попадается в текстах для чтения.
- **Способы написания:**
	- Слитно: одно слово.
	- Через дефис: два слова, соединенных знаком `-`.
- **Примеры существительных:**
	- Classroom (class + room) — классная комната
	- Postcard (post + card) — открытка
	- Raincoat (rain + coat) — дождевик
	- Airport (air + port) — аэропорт
	- Boyfriend / girlfriend — парень / девушка
- **Примеры прилагательных:**
	- Well-known — известный
	- Good-looking — привлекательный
	- First-class — первоклассный
- **Примеры наречий и местоимений:**
	- Everywhere (every + where) — везде
	- Inside (in + side) — внутри
	- Somebody / anything / nowhere — кто-то / что-либо / нигде

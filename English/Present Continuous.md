# Present Continuous
- **Суть:** Действие разворачивается прямо сейчас, в момент речи.
- **Схемы предложений:**
	- ➕ `am / is / are` + `V-ing`
	- ➖ `am not / isn't / aren't` + `V-ing`
	- ❓ `Am / Is / Are` + подлежащее + `V-ing`?
- **Слова-маркеры:**
	- Now — сейчас
	- At the moment — в данный момент
	- Look! — Посмотри!
	- Listen! — Послушай!
- **Пример для ОГЭ:** Look! The children ==are playing== (PLAY) in the yard.

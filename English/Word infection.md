# Словоизменение (Word inflection)
- **Суть:** Изменение грамматической формы слова (времени, числа, падежа) без изменения его части речи и базового значения. Основной инструмент для заданий 20–28 в ОГЭ.
- **Изменение форм глагола:**
	- Добавление окончаний для правильных глаголов: walk → walked, play → playing.
	- Изменение форм неправильных глаголов (из таблицы): go → went → gone, buy → bought.
- **Изменение форм существительных:**
	- Образование множественного числа по правилу: book → books.
	- Формы существительных-исключений: child → children, man → men, tooth → teeth.
- **Изменение форм местоимений:**
	- Переход из личных в объектные или притяжательные: I → me → my, they → them → their.
- **Степени сравнения прилагательных и наречий:**
	- Односложные: big → bigger → the biggest.
	- Многосложные: beautiful → more beautiful → the most beautiful.
	- Исключения: good → better → the best, bad → worse → the worst.
- **Пример для ОГЭ (Задания 20–28):**
	- Context: Two ___ (CHILD) were playing in the garden.
	- Ответ: children
